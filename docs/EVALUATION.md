## Interpretation

- The deterministic rule engine reaches recall 1.00 on OT/ICS and 1.00 on configuration samples, with a false-positive rate of 0.00 on safe OT samples. These samples were written together with the rules, so the numbers show the rules behave as specified; they are not an estimate of performance on unseen code.
- Its recall on classic AppSec samples is 0.00: by design the rule packs do not try to detect SQL injection, XSS or memory-safety bugs. That gap is what SAST and the LLM are for.
- Bandit only analyses Python, so it misses every JavaScript, Java, C++ and Go sample; its AppSec recall is 0.40 and its overall precision 0.53 (import-level warnings such as B401 count as false positives here).
- **LLM and hybrid engines have not been measured yet.** No recorded model responses are committed, and numbers are never made up. Run `python -m eval.run --engine all --live --record --write` once with a configured `OPENAI_MODEL` to record responses; afterwards the offline evaluation replays them for free.
